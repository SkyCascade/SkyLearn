## 🔄 Изменённая логика (упрощённо)

```javascript
// ❌ СТАРЫЙ КОД (неправильно):
loadGrades() {
  оценки = загрузить оценки курса
  
  if (есть оценки) {
    студенты = загрузить студентов ИЗ ОЦЕНОК  ← ❌ Только с оценками!
  } else {
    студенты = загрузить всех студентов группы
  }
}

// ✅ НОВЫЙ КОД (правильно):
loadGrades() {
  студенты = загрузить ВСЕХ студентов группы  ← ✅ Всегда всех!
  оценки = загрузить существующие оценки курса
  
  для каждого студента:
    если у него есть оценка → использовать её
    иначе → создать пустую (0, 0, 0)
}
```

## 📝 Что изменилось в коде

**Файл:** `skyfront/src/pages/crud/teacher/TeacherGradesPage.jsx`

### Изменено:

1. **Функция `loadGrades`** - теперь сначала загружает студентов, потом оценки
2. **Функция `loadStudentsFromGroup`** - возвращает список студентов
3. **Новая функция `mergeStudentsWithGrades`** - объединяет студентов с оценками

### Ключевой код:

```javascript
// СНАЧАЛА все студенты
const studentsList = await loadStudentsFromGroup(groupName);

// ПОТОМ оценки
const gradesData = await api.get(endpoint);

// Объединяем
mergeStudentsWithGrades(studentsList, gradesData, courseId);
```

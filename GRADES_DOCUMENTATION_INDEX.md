## 📞 Поддержка

### При проблемах:

1. **Страница не загружается**
   - Проверьте серверы: backend (8000) и frontend (5173)
   - Логи: консоль браузера (F12) + терминал Django

2. **Новый студент не отображается**
   - Проверьте консоль: должно быть "Loaded X students from group"
   - Проверьте, что студент в правильной группе
   - Проверьте Django логи: GET /accounts/api/groups/{name}/students

3. **Оценки не сохраняются**
   - Проверьте валидацию (0-30, 0-30, 0-40)
   - Проверьте права доступа (только преподаватели)
   - Проверьте консоль: POST bulk-update статус 200?

4. **Буквенная оценка неправильная**
   - Проверьте Total: sum(attendance + activities + exam)
   - Таблица оценок: [GRADES_LOGIC_DOCUMENTATION.md](./GRADES_LOGIC_DOCUMENTATION.md)

## ✨ Дополнительная информация

### API Endpoints:

```
GET /accounts/api/groups/{group_name}/students
→ Возвращает всех студентов группы

GET /result/api/grade-1st-modules/?course={courseId}
→ Возвращает оценки 1-го модуля

GET /result/api/grade-2nd-modules/?course={courseId}
→ Возвращает оценки 2-го модуля

GET /result/api/grade-semesters/?course={courseId}
→ Возвращает оценки семестра

POST /result/api/lecturer/bulk-grades/bulk-update/
→ Bulk обновление/создание оценок
```

### Models (Backend):

```python
Grade_1st_module:
  - lecturer (FK)
  - student (FK)
  - course (FK)
  - attendance (0-30)
  - activities (0-30)
  - exam (0-40)
  - total (0-100)

Grade_2nd_module:
  - (аналогично)

Grade_semester:
  - (аналогично + semester FK)
```

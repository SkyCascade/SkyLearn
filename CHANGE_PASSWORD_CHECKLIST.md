## Проблемы и решения 🔧

### Частые проблемы:

**401 Unauthorized**
→ Проверьте JWT токен в localStorage
→ Убедитесь, что токен актуален

**400 Bad Request**
→ Проверьте формат данных
→ Убедитесь, что все поля заполнены

**CORS ошибка**
→ Проверьте настройки CORS в Django
→ Убедитесь, что frontend URL добавлен в ALLOWED_HOSTS

**Форма не отправляется**
→ Откройте консоль браузера
→ Проверьте Network tab в DevTools
→ Проверьте, что API URL правильный

# Решение проблемы: "Курсы не загружены" / "Группы не загружены"

## Проблема

При попытке создать расписание в форме показываются ошибки:

- ⚠️ Курсы не загружены. Проверьте консоль для деталей.
- ⚠️ Группы не загружены. Проверьте консоль для деталей.

## Причина

У администратора нет созданных курсов и групп в системе.

## Решение

### Способ 1: Автоматическое создание тестовых данных (БЫСТРО)

Запустите скрипт для создания тестовых данных:

```bash
cd /Users/adminbaike/Desktop/projects/SkyLearn
python create_test_schedule_data.py
```

**Что создается:**

- ✅ 1 Программа (Computer Science)
- ✅ 4 Курса (CS101, CS102, MATH101, ENG101)
- ✅ 3 Группы (CS-101, CS-102, CS-103)
- ✅ 1 Семестр (Fall)

### Способ 2: Создание через веб-интерфейс (РУЧНОЕ)

#### Создание курсов:

1. **Перейдите на страницу управления курсами:**
   http://localhost:5174/admin/courses

2. **Создайте программу (Program):**

   - Нажмите кнопку создания программы
   - Заполните: Title, Summary
   - Сохраните

3. **Создайте курс (Course):**
   - Нажмите кнопку создания курса
   - Заполните обязательные поля:
     - Code (например: CS101)
     - Title (например: Introduction to Programming)
     - Program (выберите созданную программу)
     - Credit (например: 3)
     - Level (например: 100)
     - Year (например: 1)
   - Сохраните

#### Создание групп:

1. **Перейдите на страницу создания студентов:**
   http://localhost:5174/admin/create-students

2. **Создайте студента:**
   - Заполните форму
   - В поле "Group" введите название новой группы (например: CS-101)
   - Группа создастся автоматически при создании студента

**ИЛИ**

Через Django Admin:

- http://localhost:8000/admin/accounts/group/
- Нажмите "Add Group"
- Введите название группы
- Выберите Admin (текущего администратора)
- Сохраните

1. **Обновите страницу расписания:**

   - Нажмите F5 или Ctrl+R (Cmd+R на Mac)
   - ИЛИ нажмите кнопку "🔄 Обновить" на странице

2. **Попробуйте создать расписание:**
   - Нажмите "+ Добавить занятие"
   - В dropdown "Курс" должны появиться созданные курсы
   - В dropdown "Группа" должны появиться созданные группы

## Важные замечания

### Multi-tenancy (изоляция данных)

Каждый администратор видит **только свои** данные:

- ✅ Курсы с полем `admin = текущий_администратор`
- ✅ Группы с полем `admin = текущий_администратор`
- ✅ Расписание только для своих курсов и групп

### API эндпоинты

Проверьте в DevTools (F12 → Network) что запросы успешны:

```
✅ GET /programs/api/course/   → 200 OK (список курсов)
✅ GET /accounts/api/groups/   → 200 OK (список групп)
```

Если видите пустые массивы `[]` - значит данных нет, нужно создать.

# Руководство по управлению временами уроков - Фронтенд

## Обзор

Реализована полная фронтенд интеграция для управления временами уроков. Теперь администратор может:

1. **Создавать стандартные времена уроков** - определить когда начинается и заканчивается каждый урок
2. **Использовать времена уроков при создании расписания** - выбирать из предустановленных времен вместо ручного ввода
3. **Редактировать и удалять времена уроков** - изменять существующие настройки

## Новые компоненты

### 1. LessonTimes.jsx (`/admin/lesson-times`)

**Расположение:** `skyfront/src/pages/crud/LessonTimes.jsx`

**Функциональность:**

- ✅ Просмотр всех времен уроков
- ✅ Создание нового времени урока
- ✅ Редактирование существующего времени урока
- ✅ Удаление времени урока
- ✅ Валидация данных
- ✅ Уведомления об успехе/ошибке

**Поля формы:**

- `order` - Номер урока (1, 2, 3...)
- `start_time` - Время начала (HH:MM)
- `end_time` - Время окончания (HH:MM)

**API эндпоинты:**

```javascript
GET    /attendance/lesson-times/     // Получить все времена
POST   /attendance/lesson-times/     // Создать новое время
PUT    /attendance/lesson-times/:id/ // Обновить время
DELETE /attendance/lesson-times/:id/ // Удалить время
```

## Пользовательский сценарий

### Шаг 1: Настройка времен уроков

1. Админ переходит на страницу **"Manage Lesson Times"** (`/admin/lesson-times`)
2. Создает стандартные времена:
   - Урок 1: 09:00 - 10:30
   - Урок 2: 10:40 - 12:10
   - Урок 3: 12:20 - 13:50
   - Урок 4: 14:00 - 15:30

### Шаг 2: Создание расписания

1. Админ переходит на страницу **"Manage Schedule"** (`/admin/schedule`)
2. Нажимает "Добавить занятие"
3. Выбирает:
   - Курс
   - Группу
   - День недели
   - **Время урока** (из dropdown: "Урок 1: 09:00 - 10:30")
   - Опционально: конкретную дату
4. Система автоматически определяет start_time и end_time

### Шаг 3: Редактирование

- Можно изменить время урока, выбрав другой вариант из dropdown
- Можно указать конкретную дату для урока
- Все изменения сохраняются в базе данных

## Структура данных

### LessonTime (ответ от API)

```json
{
  "id": 1,
  "order": 1,
  "start_time": "09:00:00",
  "end_time": "10:30:00",
  "admin": 1
}
```

### ScheduleItem (расширенный ответ от API)

```json
{
  "id": 1,
  "course": 1,
  "course_title": "Introduction to Programming",
  "course_code": "CS101",
  "group": 1,

  "date": "2024-01-15",
  "start_time": "09:00:00", // Вычисляется из lesson_time

```

## Преимущества новой системы

1. **Консистентность** - Все уроки используют одинаковые времена
2. **Удобство** - Не нужно каждый раз вводить время вручную
3. **Гибкость** - Можно изменить время для всех уроков одновременно
4. **Централизованное управление** - Все времена в одном месте
5. **Обратная совместимость** - Поле lesson_time опциональное

## Безопасность

- ✅ Все запросы требуют аутентификации (JWT)
- ✅ Каждый админ видит только свои времена уроков
- ✅ CRUD операции доступны только аутентифицированным админам
- ✅ Multi-tenancy: админы изолированы друг от друга

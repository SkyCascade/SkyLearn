# Функциональность Смены Пароля - Краткая Инструкция

## ✅ Что было сделано

### Backend (Django)

1. **Сериализатор** (`accounts/serializers.py`):

   - `ChangePasswordSerializer` - валидация и обработка смены пароля
   - Проверка старого пароля
   - Проверка совпадения нового пароля
   - Валидация сложности пароля

2. **View** (`accounts/views.py`):

   - `ChangePasswordView` - API endpoint для смены пароля
   - Доступен для всех аутентифицированных пользователей
   - Сохраняет сессию после смены пароля

3. **URL** (`accounts/urls.py`):
   - Маршрут: `/accounts/change-password/`

### Frontend (React)

1. **Компонент** (`skyfront/src/componenets/ChangePassword.jsx`):

   - Форма смены пароля
   - Показ/скрытие пароля
   - Индикатор силы пароля
   - Валидация на клиенте
   - Советы по безопасности

2. **Маршрут** (`skyfront/src/App.jsx`):

   - URL: `/change-password`
   - Защищен аутентификацией

3. **Интеграция в профили**:
   - Студент (`student.jsx`) - кнопка в Quick Actions
   - Учитель (`teacher.jsx`) - кнопка в Quick Actions
   - Админ (`admin.jsx`) - отдельная секция Security Settings

## 🚀 Как использовать

### Для пользователей:

1. Войдите в систему как студент/учитель/админ
2. На главной странице найдите кнопку **"Change Password"** 🔒
3. Нажмите на кнопку
4. Заполните форму:
   - **Current Password** - ваш текущий пароль
   - **New Password** - новый пароль (минимум 8 символов)
   - **Confirm New Password** - повторите новый пароль
5. Нажмите кнопку **"Change Password"**
6. После успешной смены появится зеленое уведомление

### Требования к паролю:

✅ Минимум 8 символов
✅ Заглавные и строчные буквы
✅ Минимум одна цифра
✅ Минимум один специальный символ (!@#$%^&\*)

## 📝 API Endpoint

```
POST /accounts/change-password/
Authorization: Bearer <token>

{
  "old_password": "старый_пароль",
  "new_password": "новый_пароль",
  "confirm_password": "новый_пароль"
}
```

## ❓ Возможные ошибки

**"Old password is incorrect"**
→ Вы неправильно ввели текущий пароль

**"New passwords do not match"**
→ Новый пароль и подтверждение не совпадают

**"This password is too short"**
→ Пароль должен содержать минимум 8 символов

**"This password is too common"**
→ Выберите более уникальный пароль

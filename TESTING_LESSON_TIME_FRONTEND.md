# Инструкция по тестированию интеграции времен уроков

## Предварительные требования

1. ✅ Backend запущен на `http://localhost:8000`
2. ✅ Frontend запущен на `http://localhost:5174`
3. ✅ База данных с миграциями применена
4. ✅ Есть учетная запись администратора

## Шаги тестирования

### 1. Войти в систему как администратор

1. Откройте `http://localhost:5174/login`
2. Введите учетные данные администратора
3. После входа вы должны увидеть Admin Dashboard

### 2. Тестирование страницы управления временами уроков

#### 2.1 Переход на страницу

1. На Dashboard найдите кнопку **"manage lesson times"**
2. Нажмите на нее
3. Откроется страница `/admin/lesson-times`

#### 2.2 Создание времен уроков

Создайте стандартные времена уроков:

**Урок 1:**

- Номер урока: 1
- Время начала: 09:00
- Время окончания: 10:30
- Нажмите "Добавить"

**Урок 2:**

- Номер урока: 2
- Время начала: 10:40
- Время окончания: 12:10
- Нажмите "Добавить"

**Урок 3:**

- Номер урока: 3
- Время начала: 12:20
- Время окончания: 13:50
- Нажмите "Добавить"

**Урок 4:**

- Номер урока: 4
- Время начала: 14:00
- Время окончания: 15:30
- Нажмите "Добавить"

#### 2.3 Проверка списка

После создания вы должны видеть:

- 4 карточки с временами уроков
- Каждая карточка показывает: номер урока, время начала и окончания
- Кнопки "Редактировать" и "Удалить"

#### 2.4 Редактирование времени урока

1. Нажмите кнопку "Редактировать" на любом уроке
2. Измените время (например, измените начало с 09:00 на 09:10)
3. Нажмите "Сохранить"
4. Проверьте, что изменения отображаются в списке

#### 2.5 Удаление времени урока

1. Нажмите кнопку "Удалить" на любом уроке
2. Подтвердите удаление
3. Проверьте, что урок удален из списка

### 3. Тестирование интеграции с расписанием

#### 3.1 Переход на страницу расписания

1. Вернитесь на Dashboard (кликните лого или используйте навигацию)
2. Нажмите кнопку **"manage schedule"**
3. Откроется страница `/admin/schedule`

#### 3.2 Создание расписания с временем урока

**Предварительно убедитесь, что у вас есть:**

- Хотя бы один курс
- Хотя бы одна группа
- Хотя бы одно время урока

**Создание:**

1. Нажмите "Добавить занятие"
2. Заполните форму:
   - Курс: выберите из списка
   - Группа: выберите из списка
   - День недели: выберите (например, Monday)
   - **Время урока: выберите "Урок 1: 09:00 - 10:30"**
   - Дата урока: (опционально) выберите дату
3. Нажмите "Создать"

#### 3.3 Проверка созданного расписания

В списке расписания вы должны увидеть:

- Название курса и код
- Название группы
- Время урока (09:00 - 10:30)
- Бейдж "Урок 1" (синий бейдж с номером урока)
- Дату урока (если указали)

#### 3.4 Создание расписания без времени урока

1. Нажмите "Добавить занятие"
2. Заполните форму, но **НЕ выбирайте** время урока
3. Нажмите "Создать"
4. Должно успешно создаться (поле опциональное)

### 4. Проверка изоляции данных (Multi-tenancy)

#### 4.1 Создание второго администратора

```bash
# В терминале Django
python manage.py shell

# Создание второго админа
from accounts.models import User
admin2 = User.objects.create_user(
    username='admin2',
    email='admin2@test.com',
    password='admin123',
    first_name='Admin',
    last_name='Two',
    is_superuser=True,
    is_staff=True
)
```

#### 4.2 Тестирование изоляции

1. Выйдите из первого аккаунта (Logout)
2. Войдите как второй администратор (admin2)
3. Перейдите на страницу управления временами уроков
4. Вы НЕ должны видеть времена уроков первого админа
5. Создайте свои времена уроков
6. Они не должны быть видны первому админу

## Возможные проблемы и решения

### Проблема: "Курсы не загружены"

**Решение:** Создайте курс через `/admin/courses`

### Проблема: "Группы не загружены"

**Решение:** Создайте группу через `/admin/create-students` или `/admin/create-lecturers`

### Проблема: 401 Unauthorized

**Решение:** Перелогиньтесь в систему

### Проблема: CORS ошибки

**Решение:** Проверьте настройки CORS в Django settings

### Проблема: Времена не отображаются в dropdown

**Решение:**

1. Проверьте консоль браузера на ошибки
2. Убедитесь, что создали хотя бы одно время урока
3. Проверьте Network tab в DevTools
